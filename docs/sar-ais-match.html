What this page shows

GFW 的「暗船」標記是用他們自己的 AIS 來源比對的；本站接的航港局 AIS 在台海近岸密度更高。 本頁把 GFW 標為 unmatched 的 SAR 偵測，拿本地 AIS 重新比對一次 —— 先過濾風機／養殖平台等固定設施， 再把 AIS 軌跡以航位推算內插到衛星過境時刻、用動態半徑做一對一匹配。剩下的才是「驗證後殘餘暗船」。

GFW's "dark vessel" flag is made against GFW's own AIS feed; the local Port Bureau AIS feed is denser near Taiwan. This page re-matches every GFW-unmatched SAR detection against local AIS — first filtering fixed infrastructure (wind turbines, aquaculture platforms), then dead-reckoning AIS tracks to the satellite overpass instant and matching one-to-one with a dynamic gating radius. What remains is the screened residual dark-vessel set.

  • 被本地 AIS 對上的偵測 ＝ 假暗船（GFW 的 AIS 漏了，不是真的關 AIS）。
  • A detection matched by local AIS is a false dark ship (missed by GFW's AIS feed, not actually dark).
  • 殘餘暗船以 0.1° 密度熱圖與 12浬／24浬鄰接區／EEZ 每日時間序列呈現。
  • Residual dark ships are shown as a 0.1° density heatmap and daily series by 12 nm / 24 nm contiguous zone / EEZ.

🔬 方法與限制🔬 Method & limitations
  1. 固定設施過濾：同一 0.01° 網格在資料窗內 ≥6 個不同日期都被偵測為「暗船」→ 判定為風機／平台／養殖等固定設施（船不會天天停在同個 SAR 網格）。
  2. 時間內插：SAR 成像是瞬時的，AIS 為 2 小時快照。比對前先把 AIS 軌跡內插／航位推算（速度×航向）到 Sentinel-1 過境時刻（升軌 ≈09:50 UTC、降軌 ≈21:55 UTC）。
  3. 動態匹配半徑：門檻 = SAR 定位誤差 + 網格量化誤差 + AIS 誤差 + 航速×時距的機動不確定性，夾在 1.5–10 km，不用固定半徑。
  4. 一對一指派：每個過境內以匈牙利演算法（或貪婪最近鄰 + gating）指派，密集區不會一船吸掉多筆偵測。
  5. 限制：SAR 資料窗 30 天，但本地 AIS 軌跡僅保留 14–28 天 —— 覆蓋窗之前的偵測「無從驗證」，會標示為 no-coverage、不計入比中率；殘餘暗船代表「本地 AIS 也對不上的目標」，不必然代表違法行為。浮標／漁網信標等非船舶 AIS 發射器已排除，不會拿來「洗白」暗船。
  1. Fixed-infrastructure filter: a 0.01° cell dark-detected on ≥6 distinct dates in the window is classified as infrastructure (turbines, platforms, aquaculture) — ships don't park in the same SAR cell daily.
  2. Time interpolation: SAR imaging is instantaneous while AIS is a 2-hour snapshot. AIS tracks are interpolated / dead-reckoned (speed × heading) to the Sentinel-1 overpass instant (ascending ≈09:50 UTC, descending ≈21:55 UTC).
  3. Dynamic gating radius: threshold = SAR geolocation error + grid quantization + AIS error + speed×Δt maneuver uncertainty, clamped to 1.5–10 km — never a fixed radius.
  4. One-to-one assignment: per satellite pass, detections are assigned via the Hungarian algorithm (or gated greedy nearest-neighbour), so one vessel cannot absorb several detections in dense areas.
  5. Limitations: the SAR window is 30 days but local AIS tracks are retained 14–28 days — detections before the coverage window are unverifiable, flagged as no-coverage, and excluded from the match rate. A residual dark ship is a target local AIS also cannot explain, not necessarily illegal activity. Non-vessel AIS transmitters (buoys, net beacons) are excluded so they cannot "launder" dark ships.
